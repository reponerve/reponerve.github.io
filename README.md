# RepoNerve Website

Official site for [RepoNerve](https://github.com/reponerve/reponerve): **https://reponerve.github.io/**

Repository: **`reponerve/reponerve.github.io`** (GitHub Pages org site — rename from `landing` before go-live).

## Go-live checklist

After renaming the repo to `reponerve.github.io`:

1. **GitHub → Settings → Pages** — Source: **GitHub Actions**
2. **Push to `main`** — `pages.yml` builds and publishes `dist/` to https://reponerve.github.io/
3. **Secret (optional, recommended)** — In `reponerve/reponerve`, add `WEBSITE_SYNC_TOKEN` (fine-grained PAT with `contents: write` on `reponerve/reponerve.github.io`) so each product release triggers a site-data sync
4. **Verify** — Open https://reponerve.github.io/, confirm version badge matches [latest release](https://github.com/reponerve/reponerve/releases)

No `base` path change needed — `vite.config.ts` uses `base: '/'` for the org root URL.

## Staying aligned with reponerve/reponerve

Factual content lives in **`src/site-data.json`**, generated by `scripts/sync-site-data.mjs`:

```bash
npm run sync
# offline / pre-release:
REPONERVE_LOCAL=/path/to/reponerve npm run sync
```

| Field | Source in product repo |
| --- | --- |
| Version | GitHub Releases latest tag |
| `go install …@vX.Y.Z` | Derived from version |
| Language count (20) | `internal/code/lang/lang.go` |
| MCP tool count (49) | `internal/mcp/registry.go` |
| CLI demo output | Matches real `init` / `scan` / `doctor` messages |
| Config presets | Valid `config.yaml` schema (`internal/config/config.go`) |

### Automation

| Workflow | Repository | Trigger |
| --- | --- | --- |
| `ci.yml` | `reponerve.github.io` | PR + push — lint, sync check, build |
| `sync-site-data.yml` | `reponerve.github.io` | Weekly, manual, `reponerve-released` dispatch |
| `pages.yml` | `reponerve.github.io` | Push to `main` |
| `release.yml` → `notify-website` | `reponerve/reponerve` | Tagged release |

`npm run build` runs `sync` first (`prebuild`) so production builds always pull current facts from GitHub.

## Local development

```bash
npm install
npm run dev      # http://localhost:3000
npm run sync     # refresh src/site-data.json
npm run build    # sync + production bundle → dist/
npm run preview  # serve dist/
```
